Optional custom alert sounds
============================

Drop audio files in this folder to override generated fallback tones.
Supported extensions: .mp3, .wav, .ogg

Recognized names:
- tornado.mp3 / high.mp3
- severe-thunderstorm.mp3
- flash-flood.mp3
- warning.mp3
- watch.mp3
- advisory.mp3
- statement.mp3 / alert.mp3
- admin-green.mp3 / administrative-green.mp3
- admin-red.mp3 / administrative-red.mp3

If no matching file exists, HWOS automatically plays the built-in generated tone.
